# Manual in-game checklist

Run this list in each flavor that you can reach before each release.
Write `pass` or `fail` and the date in each cell.

| Trigger | How to cause it | Retail | MoP | Titan | TBC | Forever | Era | Pass/fail/date |
|---|---|---|---|---|---|---|---|---|
