# Paparazzi

**Paparazzi takes a screenshot when something important happens in your game.** It also records why it took each one.

## What it captures

- **Progress:** level up, achievement, guild achievement, achievement criteria, reputation rank, renown level, new recipe, Traveler's Log activity.
- **Combat:** boss kill, boss wipe, world boss kill, Mythic+ completed, Mythic+ new record, Delve completed, death, close call (your health drops under 20% and recovers).
- **Collections:** new mount, new pet, new toy, new housing item, house level.
- **PvP:** PvP match won, duel finished.
- **Loot and trade:** epic loot, legendary loot, trade.
- **World:** login, first visit to a zone.

## Features

- **Per-trigger control:** turn each trigger on or off. Set a delay of 0 to 5 seconds for each one.
- **Merge window:** events that happen close together make one screenshot. Set the window from 2 to 10 seconds.
- **Capture log:** the addon keeps 100 to 5000 records of what it captured and why.
- **Light on the game:** the addon does not read the combat log. It does not change your settings or your interface.

## Use

- Type `/paparazzi` to open the settings.
- Type `/paparazzi test` to take one test screenshot.
- In Retail, you can also open the settings from the addon compartment.

## Export the reasons (optional)

The game cannot write files from an addon. The free **paparazzi-export** tool solves this. It reads your saved data and writes a `.json` file next to each screenshot. The file says why the screenshot exists.

- It runs on Windows, macOS, and Linux.
- It never changes your images.
- Download it from the GitHub Releases page.

## Known limits

- A game crash loses the records that are not saved yet.
- A manual screenshot just after an automatic one can get the wrong record.
- `/reload` or logout cancels a pending screenshot.
